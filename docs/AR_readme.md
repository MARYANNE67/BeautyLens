# BeautyLens — Developer Setup Guide

AR-powered makeup try-on app built with Expo + React Native. This guide walks you through building and running the app on a real iOS device using Xcode.

---

## Prerequisites

Make sure you have the following installed before starting:

| Tool | Version | Notes |
|------|---------|-------|
| Node.js | 18 or later | [nodejs.org](https://nodejs.org) |
| npm | comes with Node | |
| Xcode | 15 or later | Mac App Store |
| CocoaPods | latest | `sudo gem install cocoapods` |
| Git | any | usually pre-installed on Mac |

You also need a **free Apple Developer account** (no paid membership required to run on your own device via Xcode). Sign in at [developer.apple.com](https://developer.apple.com) with your Apple ID.

---

## 1. Clone the repo

```bash
git clone <your-repo-url>
cd beautylens
git checkout ar_tryon
```

---

## 2. Install JavaScript dependencies

```bash
npm install
```

---

## 3. Generate the native iOS project

Because this app uses native modules (WebView, camera, SVG), it cannot run in Expo Go. You need to generate the native Xcode project with:

```bash
npx expo prebuild --platform ios --clean
```

This creates an `ios/` folder with a full Xcode project inside. You only need to re-run this if `package.json` dependencies change.

---

## 4. Install iOS (CocoaPods) dependencies

```bash
cd ios
pod install
cd ..
```

This may take a few minutes the first time.

---

## 5. Open in Xcode

```bash
open ios/beautylens.xcworkspace
```

> **Important:** Always open the `.xcworkspace` file — NOT the `.xcodeproj` file. Opening `.xcodeproj` will cause build errors.

---

## 6. Configure signing in Xcode

1. In Xcode, click the **beautylens** project in the left sidebar
2. Select the **beautylens** target
3. Go to the **Signing & Capabilities** tab
4. Check **Automatically manage signing**
5. Under **Team**, select your Apple ID (add it via Xcode → Settings → Accounts if not listed)
6. Xcode will generate a free provisioning profile automatically

> Free provisioning profiles expire after **7 days**. You'll need to rebuild and re-sign to reinstall after that.

---

## 7. Connect your iPhone and build

1. Plug your iPhone into your Mac with a USB cable
2. In Xcode, select your iPhone from the device picker at the top (e.g. "iPhone 15 — iPhone")
3. The first time you connect, tap **Trust** on your iPhone when prompted
4. Press **⌘R** (or the ▶ Play button) to build and install

The first build takes 3–5 minutes. Subsequent builds are faster.

---

## 8. Start the Metro bundler (JS server)

In a separate terminal, from the project root:

```bash
npx expo start
```

Keep this running while you use the app. If you close it, the app will show a blank/error screen.

---

## 9. Backend API (required for product detection and shade preview)

The app calls a local Python backend for:
- **Product detection** (`POST /detect`)
- **Shade photo preview** (`POST /tryon/preview`)

To start the backend:

```bash
# From the project root
cd src/api
pip install -r requirements.txt   # first time only
uvicorn main:app --reload --port 8000
```

The app auto-detects the backend URL from the Metro bundler host — no config needed on the same Wi-Fi network.

---

## Environment variables (optional)

Create a `.env` file in the project root if you need to override the backend URL:

```
EXPO_PUBLIC_API_BASE_URL_DEV=http://192.168.x.x:8000
EXPO_PUBLIC_API_BASE_URL_PROD=https://your-production-api.com
```

## Troubleshooting

**"No team" error in Xcode signing**
→ Go to Xcode → Settings → Accounts → add your Apple ID

**Pod install fails**
```bash
sudo gem install cocoapods
pod repo update
cd ios && pod install
```

**"Unable to boot device" or app won't install**
→ Unplug and replug the iPhone, trust the Mac again, then rebuild

**App opens but shows blank screen**
→ Make sure `npx expo start` is running in a terminal

**Camera permission denied**
→ Go to iPhone Settings → Privacy → Camera → enable for BeautyLens

**Product detection not working**
→ Make sure the Python backend is running (`uvicorn main:app --port 8000`) and your phone and Mac are on the same Wi-Fi network

## Project structure (key files)

```
beautylens/
├── src/
│   ├── app/
│   │   ├── scan.tsx          # Camera scan screen (product detection)
│   │   ├── tryon.tsx         # Shade picker screen
│   │   ├── camera.tsx        # Live AR try-on screen
│   │   └── shade-preview.tsx # Photo-based shade preview
│   ├── components/
│   │   └── ARMakeupWebView.tsx  # WebView AR renderer (MediaPipe FaceMesh)
│   ├── api/
│   │   └── tryon_render.py   # Python backend for shade blending
│   └── config/
│       └── featureFlags.ts   # Feature toggles and API config
├── ios/                      # Generated by expo prebuild (do not edit manually)
└── package.json
```

---

## Feature flags

Key flags in `src/config/featureFlags.ts`:

| Flag | Default | Description |
|------|---------|-------------|
| `ENABLE_OPENMAKEUP_SDK` | `true` | Uses WebView-based AR renderer |
| `ENABLE_FACE_MESH` | `true` | MediaPipe FaceMesh tracking |
| `USE_MOCK_DETECTIONS` | `false` | Skip camera, use hardcoded test detection |

Set `USE_MOCK_DETECTIONS: true` to test the AR flow without pointing the camera at a real product.
